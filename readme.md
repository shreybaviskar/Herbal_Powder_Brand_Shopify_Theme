# Minimalist Skeletal Shopify Theme 🌿🍊

A custom-coded, high-performance Shopify OS 2.0 theme tailored for a clean, editorial storefront aesthetic. Designed with a focus on visual clarity, lightning-fast interactive search, and an affiliate-catalog hybrid structure that redirects product transactions directly to Amazon.

## 🚀 Key Features

* **Skeletal & Minimalist Aesthetic**: Clean lines, a crisp white layout, monospace pricing elements, and signature brand accents (`#678b6f` Green & `#eba14e` Orange).
* **Live Dynamic Predictive Search**: Instant dropdown search overlay connected directly to Shopify's Suggestion API, supporting partial word/prefix matching for products and collections without page reloads.
* **Affiliate-Optimized Product Pages**: Streamlined architecture built specifically for catalog/affiliate setups, featuring a sticky product info column, clean thumbnail gallery switching, full-resolution image lightbox zoom, key feature bullet points, and a prominent "Shop on Amazon" call-to-action button.
* **Modular Sections**: Custom drag-and-drop sections including a specialized Bulk Orders info block on the contact page and dynamic related product recommendations.
* **Vanilla JavaScript & Liquid**: Zero heavy third-party app bloat—built natively using Vanilla JS and Shopify Liquid for maximum loading speed.

## 🛠️ Tech Stack

* **Platform**: Shopify OS 2.0
* **Templating**: Liquid
* **Styling**: Modular CSS / Custom CSS variables
* **Interactivity**: Vanilla JavaScript (Fetch API, DOM manipulation, custom lightbox modal)
